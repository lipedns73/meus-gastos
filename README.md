# Meus Gastos

Painel pessoal de gastos por categoria, com metas mensais.

- Sobe o extrato do banco (CSV ou OFX) direto no navegador.
- Classifica sozinho por palavra-chave e aprende por nome.
- **Nenhum dado sai do navegador**: tudo fica guardado no próprio aparelho (localStorage). Este repositório tem só o programa.
